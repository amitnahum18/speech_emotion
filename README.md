# Speech Emotion Recognition - Draft Project

This is a **draft project** to learn about **machine learning with audio**.  
The goal is to explore **MFCC features** to recognize emotions from short voice recordings.

## What it does
- Records or loads audio files  
- Preprocesses audio (trimming silence, normalizing)  
- Extracts MFCC features  
- Trains a simple ML model (Random Forest)  
- Predicts emotion from new audio

## Learning Goals
- Understand audio preprocessing and feature extraction  
- Learn how to train and evaluate ML models on audio data  
- Practice real-time prediction from voice recordings

## Requirements
- Python 3.x  
- Libraries: `numpy`, `librosa`, `pandas`, `scikit-learn`, `sounddevice`, `joblib`
